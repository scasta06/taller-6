# Diario de restaurantes

1. Instala un JDK 17 o posterior y abre Eclipse IDE for Java Developers.
2. En Eclipse, selecciona **File → Import → General → Existing Projects into Workspace**. En **Select root directory**, elige la carpeta `evance` y pulsa **Finish**.
3. Abre `VentanaPrincipal.java` en `src/uniandes/dpoo/swing/interfaz/principal`. Haz clic derecho y selecciona **Run As → Java Application**. El directorio de trabajo debe ser la raíz del proyecto, donde está la carpeta `imagenes`.

Selecciona un restaurante para ver su calificación y si ya lo visitaste. Para registrar otro, pulsa **Nuevo**, marca su ubicación en el mapa, completa los datos y pulsa **Crear restaurante**. En **Ver todos** puedes alternar entre todos los restaurantes y los visitados. Los datos se conservan durante la sesión.
